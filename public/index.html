Functions

Distributions: FALSE = density / mass; TRUE = cumulative probability. Click a function to start a formula. [Brackets] mark optional arguments. In examples, {1;2;3} is a column and {1,2,3} is a row.

Keyboard & selection

Click or drag to select. Shift-click extends a range. Ctrl/Cmd-click adds another range. Click a row number or column letter to select it.

Arrows · Tab · Enter
Move between cells. Shift reverses Tab / Enter.
Shift + arrows
Extend selection.
Ctrl/Cmd + arrows
Jump to an edge of a data region. Add Shift to select.
Ctrl/Cmd + A
Select the whole grid.
Ctrl + Space · Shift + Space
Select column · select row.
Ctrl/Cmd + C / X / V
Copy / cut / paste. Internal copies adjust relative references; external paste accepts tab-separated data.
Ctrl/Cmd + D / R
Fill selection down / right from its first row / column.
Ctrl/Cmd + Z · Ctrl/Cmd + Shift + Z
Undo · redo.
F2 · double-click
Edit a cell. Escape cancels.
